The Product

Three steps. That's the whole product.

Everything in the system serves one of these three moments. Click a step to jump to its detail.

STEP 01

Onboarding

3 inputs, one LinkedIn paste, topic tags, and an interactive style picker. The system builds a complete profile in under 2 minutes.

STEP 02

Generate

Enter a topic and your take. Or hit "Surprise Me." One LLM call produces a LinkedIn post in your style with hook, body, and CTA.

STEP 03

Polish & Publish

Edit, regenerate, or reject. On finalize, the system learns from your edits and updates your style profile. Copy and paste to LinkedIn.

The Learning Loop

Each finalized post makes the next one better

The style profile is the only thing that evolves. No model fine-tuning, no training data. Just a concise 200-word document that gets tweaked on every finalize.

How it works

1
Generate — LLM produces a post using current style profile
2
Edit — User makes inline edits to the generated post
3
Finalize — System computes diff between original and final, calls LLM Call 5
4
Learn — Style profile updated (max 200 words, never longer than before). Next generation is slightly better.
✓ The agent gets better after 5-6 finalized posts. Keep reviewing and editing.

Key Constraints

Five rules that keep the system simple

These constraints prevent scope creep and context bloat. They are the guardrails for building with Cursor.

01
All stored LLM artifacts must be extremely concise. Style profile (200 words), background (150 words). Long documents bloat context and degrade output.
02
Minimize manual data entry. 3 profile fields, one paste, 3-4 topics, style picks. Everything else is LLM-generated.
03
Every table is userId-keyed. MVP is single-user, but the schema supports multi-user without restructuring. Zero-cost decision now.
04
One LLM call per action. No chains, no loops, no agents. Regenerate = same call as generate with extra input.
05
The learning loop is simple. Style profile text is the only thing that evolves. No training data, no fine-tuning, no separate feedback database.
